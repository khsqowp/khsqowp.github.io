취약점 진단 가이드

아키텍처 파악부터 센티넬 프로브, 결과 분류, 페이로드 생성까지 — 취약점 유형별 단계별 진단 마법사를 제공합니다. PortSwigger 랩 실습에 최적화되어 있습니다.

1
아키텍처 파악
파라미터 타입, 입력 위치, 기술 스택을 파악합니다.
2
센티넬 프로브
특수문자·키워드 필터링 여부를 테스트합니다.
3
취약점 분류
응답 패턴으로 취약점 유형을 식별합니다.
4
페이로드 생성
컨텍스트에 맞는 페이로드와 우회 변형을 제공합니다.

진단 대상

  • PortSwigger Web Security Academy 랩
  • CTF 웹 취약점 문제
  • 개인 환경 실습 / 버그바운티 학습
  • 내부 보안 검토 (허가된 환경)

사용 방법

  • 취약점 유형 카드를 선택합니다
  • 각 단계의 안내를 따라 진행합니다
  • 프로브 결과를 기록하면 자동 추론됩니다
  • 생성된 페이로드를 클릭하여 복사합니다
