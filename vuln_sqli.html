Step 1 — 아키텍처 파악
SQLi 발생 원인: 사용자 입력이 SQL 쿼리에 그대로 연결(concatenation)될 때 발생합니다. 입력 파라미터의 타입과 위치를 먼저 파악하면 초기 프로브 선택이 쉬워집니다.
Step 2 — 프로브 삽입 (Injection Probe)
Burp Suite 연계: 각 프로브를 Repeater에서 순서대로 전송하고 HTTP 응답 코드·바디 변화를 비교하세요. 응답 결과 버튼을 클릭해 기록하면 Step 3에서 취약점 유형이 자동 추론됩니다.
Step 3 — 취약점 분류
프로브 결과를 바탕으로 추론된 취약점 유형이 표시됩니다. 직접 선택하거나 수정할 수 있습니다.

Error-based

에러 메시지에 DB 정보가 노출됨. 직접 데이터 추출 가능.

에러 응답

UNION-based

SELECT 결과가 응답에 반영. UNION으로 데이터 직접 추출.

응답에 데이터 반영

Boolean Blind

참/거짓에 따라 응답 차이 발생. 비트 단위 데이터 추출.

응답 내용 차이

Time-based Blind

응답 지연으로 참/거짓 판별. 응답이 없을 때 사용.

응답 지연

OOB (Out-of-Band)

DNS/HTTP 채널로 데이터 전송. xp_dirtree + Collaborator.

외부 채널
